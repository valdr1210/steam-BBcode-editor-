# Steam BBCode Editor

Веб-редактор разметки Steam BBCode с интерактивным предпросмотром для оформления руководств, профилей, обзоров и сообщений в сообществе Steam.

---

## Возможности

- **Живой предпросмотр**: рендеринг текста с использованием оригинальных стилей Steam.
- **Двустороннее редактирование**: возможность писать как в окне исходного BBCode, так и прямо в окне предпросмотра с автоматической конвертацией.
- **Поддержка всех тегов Steam**:
  - Заголовки: `[h1]`, `[h2]`, `[h3]`
  - Стили текста: `[b]`, `[i]`, `[u]`, `[strike]`
  - Специальные блоки: `[spoiler]` (с кликабельным раскрытием), `[quote]`, `[code]`, `[noparse]`, `[hr]`
  - Списки: маркированные `[list]` и нумерованные `[olist]`
  - Таблицы: генератор таблиц с параметрами `equalcells` и `noborder`
  - Ссылки и превью медиа: `[url]`, виджеты YouTube, Steam Store и Steam Workshop
- **Удобство работы**:
  - Быстрое копирование готового BBCode в буфер обмена в один клик.
  - Сохранение в файл `.txt`.
  - Поддержка горячих клавиш (`Ctrl+B`, `Ctrl+I`, `Ctrl+U`, `Tab`).
  - Статистика текста (символы, слова, строки).
  - Автосохранение текста в браузере (LocalStorage).
  - Автономная работа (не требует сервера, запускается локально или через GitHub Pages).

## Таблица поддерживаемых тегов

| Тег / Синтаксис | Назначение |
| :--- | :--- |
| `[h1]...[/h1]` | Заголовок 1-го уровня |
| `[h2]...[/h2]` | Заголовок 2-го уровня |
| `[h3]...[/h3]` | Заголовок 3-го уровня |
| `[b]...[/b]` | Полужирный шрифт |
| `[i]...[/i]` | Курсив |
| `[u]...[/u]` | Подчёркнутый текст |
| `[strike]...[/strike]` | Зачёркнутый текст |
| `[spoiler]...[/spoiler]` | Скрытый текст (открывается по клику) |
| `[quote=автор]...[/quote]` | Цитата с указанием автора |
| `[code]...[/code]` | Блок кода (моноширинный шрифт) |
| `[noparse]...[/noparse]` | Отключение обработки тегов |
| `[hr][/hr]` | Горизонтальный разделитель |
| `[url=ссылка]текст[/url]` | Гиперссылка |
| `[list][*]...[/list]` | Маркированный список |
| `[olist][*]...[/olist]` | Нумерованный список |
| `[table equalcells=1]...[/table]` | Таблица с гибкими параметрами |
